# Claude Viewer 📂

> 离线查看你的 Claude 对话记录，完全本地运行，零上传，保护隐私。

**[👉 立即使用](https://oooeee999-dot.github.io/claude-viewer/claude_viewer.html)**

---

## 为什么需要这个工具？

从 Claude 导出的对话记录是 JSON 格式，普通用户很难直接阅读。这个工具让你用浏览器就能舒适地查看所有历史对话。

## 功能特点

- 🔒 **完全离线** — 文件不会上传到任何服务器，只在你的浏览器本地处理
- 📂 **拖拽即用** — 把 conversations.json 拖进去直接看
- 🔍 **搜索对话** — 快速找到你想看的内容
- 📝 **Markdown 渲染** — Claude 的回复格式完整显示
- 💾 **导出单条对话** — 把某条对话单独保存为 .txt
- 🖥️ **跨平台** — Windows、Mac 都能用，只需要浏览器

## 使用方法

1. 打开 [Claude 设置页面](https://claude.ai/settings) 导出你的对话记录
2. 点击上方「立即使用」链接
3. 把下载的 `conversations.json` 拖进页面
4. 享受舒适的阅读体验

## 隐私声明

本工具完全在浏览器本地运行，你的对话数据不会经过任何服务器，不会被任何人看到。
